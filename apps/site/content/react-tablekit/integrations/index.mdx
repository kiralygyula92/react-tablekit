The table has no opinion about how you fetch, route, style or translate. These pages show the seams.

- [React Query](/react-tablekit/integrations/react-query/) — let a query client own the cache.
- [React Router](/react-tablekit/integrations/react-router/) — keep table state in the URL the router owns.
- [Next.js](/react-tablekit/integrations/next-js/) — App Router, server components and SSR.
- [Tailwind CSS](/react-tablekit/integrations/tailwind/) — utilities instead of the visual layer.
- [i18next](/react-tablekit/integrations/i18next/) — translate from your existing catalogue.
