The controls below are generated from `DataTableProps` itself, so the playground cannot drift from
the component: a prop added to the type appears here, and one that is removed disappears. Change
anything and the table re-renders with it; the code panel shows exactly the props you have set.

<Playground />

## What to try

- Turn on **grouping** and then **column footers**, and switch `footerAggregationScope` between
  `page` and `filtered` to see which total you actually want.
- Set **pagination type** to `loadMore` or `infinite` and watch the rows accumulate rather than
  replace.
- Switch **density** and **striping** together — the whole visual system is tokens, so nothing
  reflows.
- Turn off **rows per page** and see the control disappear while paging still works.
