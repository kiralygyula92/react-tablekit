Every other page on this site shows one capability in isolation. These four show the table doing a real job, with the dense `classic` preset, server-backed data and a mock API that has latency and can be made to fail.

They are also the pages whose pixels are locked: each has a visual regression baseline at 1440px and 390px, so an accidental layout change fails the build.

- [Account list](/react-tablekit/demos/account-list/): server pagination, search in the page header, pinned row actions.
- [Asset list](/react-tablekit/demos/asset-list/): a chip list with overflow, clickable chips inside cells.
- [Reading history](/react-tablekit/demos/reading-history/): 18 columns, horizontal scroll, per-row disabled actions.
- [Asset picker](/react-tablekit/demos/asset-picker/): single selection inside a dialog, sticky header in a bounded scroll.

Two interactive tools sit alongside them:

- [Playground](/react-tablekit/demos/playground/): every prop as a control, with the code it produces.
- [Theme editor](/react-tablekit/demos/theme-editor/): edit tokens live and export a theme.
