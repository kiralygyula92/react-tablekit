## There is nothing to migrate yet

1.0.0 is the first stable release, so there is no earlier version to upgrade from.

This page exists now so the first upgrade guide has a home that will not move, and so the link from the [versions page](/react-tablekit/getting-started/versions/) is never broken.

## What a migration page will contain

When 2.0 arrives, each jump gets its own page under this section, kept online permanently, containing:

- every breaking change, with the before and after;
- a codemod where the change is mechanical;
- the deprecation warnings you should already have seen in development;
- anything that changed in the `tk-*` class names, `--tk-*` variables or `data-*` attributes, since those are public too.
