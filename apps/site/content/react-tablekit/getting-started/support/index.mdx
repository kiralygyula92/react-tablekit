## Reporting a bug

[Open an issue on GitHub](https://github.com/kiralygyula92/react-tablekit/issues). A reproduction is worth more than a description: the fastest route is a link to a [playground](/react-tablekit/demos/playground/) configuration that shows the problem, since the whole configuration lives in the URL.

Please include the version, the React version and whether the table is in client or server mode.

## Asking a question

Use GitHub issues for questions too. There is no paid support channel and no guaranteed response time — this is a free, MIT-licensed project.

## Requesting a feature

Check the [roadmap](/react-tablekit/discover-more/roadmap/) first: several capabilities are specified but deliberately deferred past 1.0. If it is not there, open an issue describing the problem you are solving rather than the API you imagine.

## Security

Report a suspected vulnerability privately through
[GitHub's security advisories](https://github.com/kiralygyula92/react-tablekit/security/advisories)
rather than a public issue. See the [security guide](/react-tablekit/guides/security/) for the threat model.
