## 1.0.0

The first stable release. The API is stable and covered by the
[semver promise](/react-tablekit/getting-started/versions/).

**What it contains.** Every feature documented under [All
features](/react-tablekit/all-features/), each working in client mode and in server mode:
sorting, global search, column filters, faceting, pagination in six presentations, row selection
with an exclusion model for select-all, expansion and tree data, grouping and aggregation, column
pinning, sizing, ordering, visibility and footers, row pinning, numbers and appearance, sticky
header and footer, density, virtualization, responsive layouts, export, persistence, keyboard
navigation, localization, and a fully headless core.

**Quality gates at release.** The end-to-end suite runs on Chromium, Firefox and WebKit: 702
tests. Server-side rendering is covered by a smoke test that asserts what reaches the first paint,
including `role="grid"` for a selectable table and the cards layout under a small `ssrBreakpoint`.
Packaging passes `publint --strict` and `@arethetypeswrong/cli` on the packed tarball.

**Bundle budgets.** The measured sizes are the guards: about 58 kB min+gzip for
`import { DataTable }`, 61.5 kB for the full import, 21 kB for `react-tablekit/core`, and under
7 kB for `styles.css`. The originally specified 24 kB basic-usage target needs the feature modules
split apart, a refactor deferred to 1.x rather than landed immediately before a stable release.
Locale packs and CSS presets are separate entry points and are never reachable from the main one.

## Before 1.0

The library was built in seven milestones (engine and rendering, search and filtering, selection
and expansion, column power features and large data, grouping and export, theming and this site,
then hardening), each ending with the full gate green. There are no pre-1.0 releases to migrate
from.
