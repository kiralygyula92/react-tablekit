## What you get

<p className="section-lead">Four things that usually cost a rewrite when you need them later.</p>

### Client and server, per feature

Pagination on the server, sorting on the page you already fetched, filters back on the server
again. Each feature picks its own side, and the table handles debouncing, aborting and races.

### Replaceable everywhere

Sixty-five slots, nineteen overridable interactions and a hundred design tokens. Change a colour
with a CSS variable; change a whole pagination bar with a component.

### Headless when you need it

`useDataTable` gives you the engine and renders nothing. `createTable` runs without React. The
batteries-included component is a convenience, not a requirement.

### Accessible because it is the default

Real table semantics, the ARIA role the enabled state requires, the data-grid keyboard pattern and
live announcements — all localized, none of it opt-in.
