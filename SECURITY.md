# Security policy

## Supported versions

Security fixes are released for the latest minor version of `react-tablekit`.

## Reporting a vulnerability

Please do **not** open a public issue. Report vulnerabilities privately through
[GitHub security advisories](https://github.com/kiralygyula92/react-tablekit/security/advisories/new).
Include the affected version, a description of the impact and, ideally, a minimal reproduction
(for example the column definitions and data that trigger it).

You can expect an acknowledgement within a few days. Once a fix is released, the advisory is
published with credit to the reporter unless you prefer to stay anonymous.
